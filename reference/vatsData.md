# Geographical, climate, and trait data of the Vataireoid legumes

A dataset of 1610 georeferenced, taxonomically vetted herbarium records
of the Vataireoid legumes, with climate data
([WorldClim](https://www.worldclim.org/data/bioclim.html)) derived from
monthly precipitation and temperature model layers. This data frame
includes additional continuous and categorical traits, such as DBH, the
probability of occurrence in the global succulent biome ([Ringelberg et
al. 2019](https://doi.org/10.1111/geb.13089)), and biome classification
(sensu [Schrire et al.
2005](http://publ.royalacademy.dk/books/120/834?lang=da)).

## Usage

``` r
data(vatsData)
```

## Format

Table in .csv format
