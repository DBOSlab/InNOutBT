# Package index

## All functions

- [`phyreg.inputs()`](https://DBOSlab.github.io/InNOutBT/reference/phyreg.inputs.md)
  : Produce BayesTraits phylogenetic regression mean and linked input
  data comprising samples of trait data
- [`phyreg.outputs()`](https://DBOSlab.github.io/InNOutBT/reference/phyreg.outputs.md)
  : Process BayesTraits phylogenetic regression output data
- [`phyreg.shell()`](https://DBOSlab.github.io/InNOutBT/reference/phyreg.shell.md)
  : Create shell scripts to run BayesTraits phylogenetic regression
  analyses using samples of trait data
- [`shell.phyreg.proj()`](https://DBOSlab.github.io/InNOutBT/reference/shell.phyreg.proj.md)
  : Create a BayesTraits project folder with associated example scripts
  and input data for a full shell script run and log processing of
  BayesTraits phylogenetic regression analyses
- [`vatsData`](https://DBOSlab.github.io/InNOutBT/reference/vatsData.md)
  : Geographical, climate, and trait data of the Vataireoid legumes
- [`vatsTree`](https://DBOSlab.github.io/InNOutBT/reference/vatsTree.md)
  : BEAST-dated phylogeny or time-tree of the Vataireoid legumes
