# BEAST-dated phylogeny or time-tree of the Vataireoid legumes

A dated phylogeny of the Vataireoid legumes from a BEAST analysis of
nine genes (nuclear ribosomal ETS and ITS, and the plastid regions matK,
3′-trnK intron, psbA-trnH, trnL intron, rps16 intron, trnQ-5′rps16, and
trnD-trnT).

## Usage

``` r
data(vatsTree)
```

## Format

Treedata file in Nexus format resulting from a BEAST analysis

## Source

[Cruz et al. (2018)](https://doi.org/10.12705/675.6)
